# Included Raw Data With Legacy Path Name

The scripts still use this folder name, so it is kept for backward compatibility. The data stored here are included in the replication package.

Current included subfolders:

- `factiva_api/Results_Factiva_API/`: packaged Factiva Analytics API query results (monthly article counts, JSON)
- `factiva_lookup/`: packaged Factiva lookup and taxonomy files

These materials are included in the package so the replication archive is self-contained. Source, access instructions, access dates, citations, and licenses are given in the Data Availability section of the top-level [`README.md`](../../../README.md) (datasets 1–2).

# Included Raw Data With Legacy Path Name

This folder name is retained for backward compatibility with the existing script paths, but the data stored here are now part of the packaged replication materials.

Current included subfolders:

- `factiva_api/Results_new/`: packaged Factiva API JSON query results
- `factiva_lookup/`: packaged Factiva lookup and taxonomy files
- `factiva_rtf_exports/`: packaged raw Factiva RTF export archive
- `VAR/`: packaged VAR and macroeconomic input files for supplementary workflows

These materials are included in the package so the replication archive is self-contained.

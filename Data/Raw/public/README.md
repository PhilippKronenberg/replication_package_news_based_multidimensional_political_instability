# Public Raw Data

This folder stores the benchmark inputs and the VAR input used by the replication workflow.

- `benchmark_data/`: packaged benchmark data sets, read by `Code/3_benchmark_data.R`
- `VAR/`: packaged VAR input file, read by `Code/run_all.m`

The provider URLs are listed in `benchmark_data/benchmark_data_websites.txt`. File names, sources, access instructions, access dates, citations, and licenses for every dataset are given in the Data Availability section of the top-level [`README.md`](../../../README.md) (datasets 3–15). Some of the benchmark sources (CNTS, Gallup, ICRG) are licensed, despite the folder name.

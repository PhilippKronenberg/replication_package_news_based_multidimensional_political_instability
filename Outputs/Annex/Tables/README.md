# Annex Tables

This folder contains the standalone annex table artifacts kept in the formal package.

Current standalone generated files:

- `article_count_summary_statistics.tex`: "Summary Statistics: Monthly Article Counts"
- `benchmark_mean_correlations.tex`: "Mean Correlations across Countries"
- `dimension_article_count_summary_statistics.tex`: "Summary Statistics for All Dimensions: Monthly Article Counts"

Canonical output rule:

- standalone LaTeX tables belong in `Outputs/Annex/Tables/`
- review PDFs, heatmaps, and other graphics belong in `Outputs/Annex/Figures/`

These files are the canonical generated annex table outputs.
